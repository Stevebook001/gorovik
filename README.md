# GoRovik

**Write. Publish. Grow. Get Discovered.**

GoRovik is an author-first platform being built around real writer problems: outlining, pacing, plot consistency, publishing, discovery, marketing and earnings.

## MVP
- Launch landing page
- Author Launchpad concept
- Author-first product positioning
- Responsive Next.js foundation

## Roadmap
Author profiles, book discovery, writing workspace, plot/pacing tools, publishing submissions, reader community, analytics, promotions, wallet/payouts, professional marketplace and GoRovik AI.

## Local development
```bash
npm install
npm run dev
```
